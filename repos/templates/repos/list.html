Making a token for one repo
  1. On GitHub, open Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Under Repository access, choose Only select repositories and pick the repo.
  3. Under Repository permissions, set Contents to Read-only, or to Read and write if KahDuke should commit to it.
  4. Generate it and paste it above. KahDuke can only reach that repo, and you can revoke the token on GitHub at any time.
